How To Set Up A MetaMask Wallet With MAGNE L1 / M Hash L2 Testnet

This will walk you through the steps of setting up and configuring a MetaMask wallet with MAGNE.AI.

NOTE: It is recommended that you set this up through Chrome.

Install MetaMask

Go to MetaMask's website and click to download and install the browser extension for your browser of choice. Make sure the extension is being offered by metamask.io.

Wallets can connect to various blockchains, with MetaMask setting Ethereum as its default blockchain. In order to connect to MAGNE L1 / M Hash L2 Testnet, we'll need to add the network to MetaMask and select it.
