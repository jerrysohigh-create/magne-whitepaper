Hardware Empowerment: The Fusion of Security and Computing

In the Web3 world, most blockchains remain confined to software layers. MAGNE.AI breaks this limitation by tightly integrating its dual-chain architecture with hardware. Through secure chips and on-device AI engines, MAGNE.AI not only ensures asset security but also delivers breakthroughs in performance, privacy, and user experience.

1.Security Architecture

Built on certified security components

MAGNE.AI Phone is designed with a layered security architecture, combining certified secure hardware, trusted execution environments, and system-level protections.

Security is treated as a core engineering requirement, integrated from hardware design to system software and application layers.

Certified Secure Components

HyperSeed N60 Secure Component

Integrates an EAL6-certified secure element with an NFC controller in a single package.

The core cryptographic and key protection capabilities are provided by the certified secure element,

following internationally accepted security architecture practices.

  • Private keys are stored and signed entirely offline
  • All transactions are signed within the chip, immune to malware attacks
  • Supports multi-signature and hardware-level recovery, ensuring robust protection

HyperSeed 72B Secure Element

A native secure element certified at EAL6, providing high-assurance cryptographic operations, secure key storage, and tamper-resistant protection.

  • Private keys are stored and signed entirely offline
  • 500,000 repeated R/W
  • 25 years of data storage

Trusted Execution Environment (TEE)

MAGNE.AI Phone Gen1 come with CC EAL2 certified UTEE OS.

Provides isolated execution environments for sensitive system operations, supporting trusted boot and runtime integrity.

System-Level Security

Together, these components support:

  • Secure key generation and storage
  • Cryptographic execution in isolated environments
  • Trusted boot and system integrity verification
  • Protection of sensitive user and application data

Security assurance is maintained through ongoing review, testing, and operational controls, rather than one-time certification alone.

Transparency & Verification

Detailed certification materials and technical documentation are available for exchanges, partners, and regulators through controlled due diligence processes.

Public-facing materials focus on status-level transparency, ensuring accuracy without exposing unnecessary implementation details.

Note: Certification scope and implementation may vary by hardware configuration, region, or production batch.
