## 图形实现

- 使用服务端生成的语义 HTML、CSS 和 SVG 图元；没有新图表库、图片生成依赖或额外动画脚本。
- 图中的主要文字保留为 HTML，随英文 / 繁体切换，支持复制、缩放及窄屏换行。
- 保留现有 Geist / Geist Mono 字体、白底、石墨黑和红色强调。并列关系不使用顺序箭头。
- SVG 分配条与金额清单来自同一数组；每项占比按总量 100% 绘制。颜色之外同时有类别、编号、数字和金额。
- 产品渲染保持原比例和透明背景；未添加白色底板，也未把代码线框冒充实物照片。
- 复杂旧截图仍提供原图链接；键盘 Enter 可以展开和收起参考区域。

## 内容范围

本轮修改图片呈现与图旁说明，没有改写当前章节正文，也没有改动 v1.0 归档。此前全文审核中的代币体系、共识、价格承诺、硬件参数和认证口径等问题仍在审核清单中。

新的架构图和安全图明确标为概念说明，不是实际部署拓扑、芯片接线图、认证证书或已发布产品界面。旧规格海报不再作为当前参数图显示；参数仍需按设备版本核对。

100 亿 MHA 总量与十项分配比例 30 / 15 / 15 / 10 / 10 / 8 / 7 / 3 / 1 / 1 保持一致；没有修改既有释放安排、执行快照、钱包连接逻辑或配置地址。

## 维护位置

- `src/components/whitepaper/figures.ts`：双语文字、SVG 图元、分配数据与旧图片映射。
- `src/app/whitepaper-figures.css`：图形样式、手机重排、打印处理。
- `src/components/whitepaper/WhitepaperDocument.tsx`：仅在 v1.1 的文档呈现入口调用转换。
- `src/app/whitepaper.css`：引入图形样式。

原始 HTML 和素材保留。转换只识别已登记的图片文件及对应章节，不替换任意 HTML；归档使用自己的呈现入口。

## 验证记录

- `checks.json`：9 页 × 2 种语言 × 4 个宽度（320/390/768/1440），共 72 项页面检查；另外 7 项检查覆盖展开/收起、分配章节跳转、语言切换保留锚点和原版归档。
- `detail-checks.json`：最终修订后的 4 个受影响章节 × 2 种语言 × 4 个宽度；核对图形溢出、图注结构、分配总额、比例及 SVG 比例尺。
- `content-hashes-before.json`：修改前全部正文与内容文件哈希，主验证脚本逐一比较。
- `screenshots/`：本轮浏览器截图，带 `final` 的文件为细节修订后的截图。
- 命令：`npm run check`、`node scripts/verify-code-figures.mjs`、`node scripts/verify-code-figures-detail.mjs`。

测试结果以对应 JSON 中的 `passed` 与命令输出为准；未进行完整屏幕阅读器测试，也未验证外部钱包/网络的实际生产功能。

## 回退

本轮开始时的入口文件和总样式保存在 `before/`。可比较后移除 `WhitepaperDocument.tsx` 中的 `renderWhitepaperFigures` 导入与调用，恢复 `html={html}`，同时移除 `whitepaper.css` 顶部对新样式的导入，即恢复原图片呈现。若此后有其他编辑，优先逆转这两处接入，避免覆盖后续修改。
