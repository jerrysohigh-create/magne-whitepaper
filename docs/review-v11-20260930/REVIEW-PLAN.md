## 结论

当前网站已经具备完整目录、双语切换和版本入口，但正文仍携带旧站的内容冲突、营销式表达、过时状态和排版残留。图片也沿用了适合旧深色背景的素材。下一轮应同时处理内容准确性、阅读顺序和配图用途，单纯调间距不足以解决问题。

本次范围：36 篇当前章节及其英文/繁体版本，首页、页脚与 Cookie 说明；31 处正文图片，涉及 30 个独立文件、9 个有图章节。逐章处理清单见 [CHAPTER-REGISTER.md](CHAPTER-REGISTER.md)，逐图清单见 [IMAGE-REGISTER.md](IMAGE-REGISTER.md)。

这是全文初审和执行规划，不代表协议源码、链上部署、认证原件、销售合同或全部教程已完成独立验证。英文旧内容中的 KaTeX 可访问文本会在索引中重复；不能把所有索引重复都当成可见重复，下面的版式问题以实际截图为准。

所有 31 处现有图片均没有独立 `figcaption`，繁体 alt 都是“MAGNE.AI 技術文件插圖”。下一轮需要逐图判断：装饰图使用适当空 alt，信息图提供说明性 alt、图注和可阅读的等价文字。

排版基准：

- 先说明、后放图；图与对应小节相邻，避免读者先看到不明用途的大图。
- 产品图以主体比例和自然留白决定尺寸，保留透明背景，不统一套白色卡片。
- 技术图按信息密度安排宽度，并提供放大或独立图页；不靠压缩整图适配手机。
- 桌面先以 640–760px 技术图宽度试排，手机以容器宽度展示；这是起始值，不是所有图强制同尺寸。
- 硬件图和证书素材不使用生成图片伪造文字、认证章或技术结构。
- 原图保留，页面使用可回退的新资产引用；v1.0 不替换。

## 4. 执行顺序与交付物

1. **建立事实与版本底表。** 逐条记录“当前文字、问题、依据、适用网络/硬件版本、截至日期、建议文字、待确认项”。优先处理代币体系、共识、性能、硬件参数、销售与认证范围。可以先完成不依赖这些结论的排版和语法修复。
2. **完成三页样板。** 项目介绍、硬件、安全与端侧 AI、Tokenomics：分别验证叙述方式、透明产品图/技术图处理、数据图表和披露结构。先在保留快照的本地版本制作，提供修改前后对照。
3. **逐章推广。** 按 36 篇登记表处理；技术教程先修示例，再整理 FAQ/术语；移除重复内容时保留旧 URL 兼容性。全部配图按清单处理，而不是只换首页。
4. **双语校对。** 检查语义、数字、限定条件、状态、锚点及图注一致性；代码与地址不可因翻译而改变。将事实核对记录与语言润色分开。
5. **版本与验收。** 保留 v1.0 原文和入口；v1.1 更新日志区分经济规则变更、事实纠错、文字整理和视觉更新。网站仍为审阅稿，待业务事实和发布文字收口后确定公开版本。

建议保留的硬边界：100 亿 MHA 总量、十项顶层分配比例、既有释放安排和已记录的历史快照不因编辑自动改变。任何发现的经济规则冲突只列为核实项；修正数学示例也要先确认计算基数。交易所用途归类继续与可观测链上转账事实分开。

验收标准：

- 每个当前状态、数字和认证表述有日期、范围与来源，或明确列为目标/待核实。
- 清除当前看到的价格下限承诺、绝对安全措辞、重复/矛盾说明；涉及历史权利的内容有单独复核记录。
- 开发者示例无 Markdown 围栏残留、无未定义变量；可在隔离的本地测试环境完成最小流程。
- 所有图片有明确用途，信息图具备等价文字；320/390/768/1440px 下主要图中文字能读，需放大的图提供可用入口。
- 中英文保持经济规则和限定条件一致；链接、目录、搜索、页脚及原版入口有效。
- 未做完整读屏测试或认证/合规复核前，不宣称全面无障碍或法务通过。
