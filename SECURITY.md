# Security reporting

Report issues affecting this whitepaper site's code or dependencies privately to info@magne.ai. Include the affected version, impact and reproduction steps. Do not send private keys, recovery phrases, production credentials or unrelated personal data.

The maintained project branch is main. The v1.0 whitepaper is a historical content archive, not a statement that its instructions remain current.

Descriptions of contracts, certificates or governance proposals do not extend an audit to this website, later deployments or revised economic rules.
