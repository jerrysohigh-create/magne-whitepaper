如何設定 MetaMask 錢包連接 MAGNE L1／M Hash L2 測試網

以下將逐步說明如何設定 MetaMask 錢包，以連接 MAGNE.AI。

注意：建議透過 Chrome 進行設定。

安裝 MetaMask

前往 MetaMask 網站，下載並安裝適用於所選瀏覽器的擴充功能。請確認擴充功能由 metamask.io 提供。

錢包可連接不同區塊鏈，MetaMask 預設使用以太坊。要連接 MAGNE L1／M Hash L2 測試網，須先將網絡新增至 MetaMask，再選取該網絡。

一鍵新增 MAGNE L1 測試網

使用 Chrome 開啟 MAGNE L1 測試網區塊瀏覽器。

按下方按鈕，即可一鍵將網絡新增至 MetaMask。

一鍵新增 M Hash L2 測試網

使用 Chrome 開啟 M Hash L2 測試網區塊瀏覽器。

按下方按鈕，即可一鍵將網絡新增至 MetaMask。

手動新增 MAGNE L1／M Hash L2 測試網

如需手動新增網絡，請按 MetaMask 左上方下拉選單。

在 MetaMask 輸入以下資料，設定網絡並連接 MAGNE L1 測試網與 M Hash L2 測試網。

正確輸入資料後，按儲存。

儲存網絡設定後，您應可連接 MAGNE L1 測試網與 M Hash L2 測試網。
