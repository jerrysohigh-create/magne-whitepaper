術語表

本草案用語

MHA / Magic Hash

現行 BSC 代幣，分配總量 100 億；未來 MAGNE 網絡用途須待啟用。

mBGT

獎勵協調與協議投票的設計用語；是否保留、發行及與 MHA 的關係仍待確認。

MagneKit

早期材料中的項目框架名稱；客戶端實作、共識引擎及發布版本仍須技術確認。

CometBFT

拜占庭容錯共識引擎；設計稿提及它不等於 MAGNE 網絡已採用。

共識

節點就接受的區塊及狀態達成一致的規則，與獎勵預算及裝置任務核驗分開。

PoW

工作量證明：採用運算競爭的一類共識，不是所有有獎運算的同義詞。

PoL

流動性證明（Proof of Liquidity）：本設計中的流動性參與及獎勵分配機制。

PoAI / GEN1

裝置工作設計及第一代裝置獎勵方案；資格、預算與釋放見代幣經濟章節。

驗證者／排序者

驗證者職責依 L1 共識，排序者排列 L2 交易；手機持有人不自動取得任一角色。

區塊／出塊時間

區塊記錄交易與狀態承諾；出塊時間須指明鏈及觀測期間。

執行客戶端／Engine API

執行客戶端處理狀態轉換；Engine API 連接執行與對應共識或 Rollup 組件，支援版本依發布版本而定。

最終確定性／提款期間

最終確定性指鏈按安全模型接受狀態為最終狀態的條件；橋接提款可能另有挑戰或處理期間。

單時隙最終確定性

按特定協議在一個時隙內完成最終確定；本術語表不宣稱 MAGNE 已實現。

質押／委託

質押使資產受特定協議規則約束。委託可分配投票或驗證權重，不一定構成資產轉移，須指明適用合約。

治理

在明確權限下提出、審閱、投票及執行變更；須明列投票資產與治理部署狀態。

DEX / MagneSwap

去中心化交易所透過合約支援兌換；本草案中的 MagneSwap 維持規劃狀態。

流動性／資金池／LP

流動性是可執行的市場深度。資金池按合約規則持有資產；流動性提供者承擔對應價格及合約風險。

獎勵金庫

管理合資格資產與已提供激勵的合約安排；准入、費率及領取規則依已部署版本而定。

已釋放／已撥付／可領取

儲備釋放按時間表提供可用預算；撥付使用獲批預算；可領取額已滿足接收者釋放條件。三者不能互換。

測試網／主網

測試網資產與紀錄供測試使用。正式／主網狀態須另有啟用記錄；測試網可用不代表正式結算。
