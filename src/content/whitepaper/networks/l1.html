MAGNE Layer 1

Public configurations currently cover MAGNE L1 and M Hash L2 testnets. Mainnet and production settlement are not open. See the official network register for deployment status and parameters.

Architecture and responsibilities

MAGNE L1 is the base-network design for identity, ownership and ecosystem coordination. EVM execution and network consensus have different responsibilities: execution updates application state, while consensus determines agreement on the accepted chain. The final consensus, validator selection and finality specification remain subject to technical confirmation.

Components and release requirements

  • Publish the client release and network configuration.
  • Specify validator admission, permissions, failure recovery and finality assumptions.
  • Keep device task rewards and validator security rewards in their respective allocation rules.

This is a role map, not a complete deployment inventory. Production disclosure must identify addresses, permissions, data availability, proof/verification configuration and recovery procedures.

Token and participation rules

Tokenomics defines reserve release and GEN1 rewards. Annual reserve schedules do not create automatic new issuance. A phone joining the task network does not thereby become a consensus validator.
