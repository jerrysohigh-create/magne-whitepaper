M Hash Layer 2

Public configurations currently cover MAGNE L1 and M Hash L2 testnets. Mainnet and production settlement are not open. See the official network register for deployment status and parameters.

Architecture and responsibilities

M Hash L2 uses an OP Stack-oriented design to execute applications and record task receipts. Execution, ordering, derivation, data publication and settlement are separate responsibilities. Asynchronous batch submission does not remove the need for consensus or settlement security on L1.

This is a role map, not a complete deployment inventory. Production disclosure must identify addresses, permissions, data availability, proof/verification configuration and recovery procedures.

Token and participation rules

Tokenomics defines reserve release and GEN1 rewards. Annual reserve schedules do not create automatic new issuance. A phone joining the task network does not thereby become a consensus validator.
