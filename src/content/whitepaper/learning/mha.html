Magic Hash (MHA)

Magic Hash (MHA) currently circulates as a token on BNB Smart Chain (BSC). The disclosed BSC contract identifies this current token; BSC transactions use BNB for network gas.

Planned network roles

Within the MAGNE network design, MHA is proposed for gas, validator security staking and ecosystem incentives. Migration or integration with MAGNE L1 and M Hash L2 will require a separate announcement covering timing, supported networks, conversion rules and holder actions. Testnet gas tokens are separate from BSC MHA and do not establish migration entitlement.

Supply and release

The allocation total remains 10,000,000,000 MHA. Release schedules describe distributions from the specified reserve pools, not new issuance above that total. Mining and validator allocations have their own schedules. Any future network fee-burning mechanism requires an explicit implementation specification; it is not a token-price commitment.

Governance design

The design also references mBGT for reward coordination and protocol voting. Its retention, transferability and relationship to MHA voting rights remain design decisions to confirm; this does not announce issuance of another token.
