What is MAGNE.AI?

MAGNE.AI combines mobile hardware, on-device AI and blockchain infrastructure. Its design connects user-controlled devices with applications and verifiable network records.

Roles in the system

LayerRole
MAG1Device interaction, local computation and protected signing paths.
MAGNE L1Base-network design for identity, ownership and ecosystem coordination.
M Hash L2EVM application execution, task receipts and contract events in the test environment.
MHAMagic Hash: the token whose allocation and release rules are set out in Tokenomics.

Network security and device rewards

L1 consensus, L2 transaction ordering and device task rewards are separate mechanisms. The v1.1 GEN1 proposal measures availability and accepted work; buying or registering a phone does not itself grant validator or block-production rights. The L1 consensus specification and its relationship to validator staking require a versioned technical confirmation.

Current stage

Public configurations currently cover MAGNE L1 and M Hash L2 testnets. Mainnet and production settlement are not open. See the official network register for deployment status and parameters.
