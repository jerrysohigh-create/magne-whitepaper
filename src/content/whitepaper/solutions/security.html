Application security boundaries

From authorisation to execution

A secure application must validate user intent, restrict permissions and expose transaction details before signing. Hardware key protection helps protect key material; it does not make an arbitrary contract call safe or remove the need to verify the recipient and requested authority.

On-chain records

Records can be inspected through the relevant explorer. Their finality depends on the network protocol; upgradeable contracts, privileged operations and off-chain inputs have separate trust assumptions. An audit covers its specified code version and scope, not every future deployment.

Operational controls

  • Publish contract versions and administrative permissions.
  • Monitor incidents, document upgrades and define recovery procedures.
  • Use least-privilege approvals and independently check high-impact transactions.
