Why M Hash uses an OP Stack design

Design objectives

The design aims to reuse an EVM-oriented rollup framework for application execution, batching and L1 settlement integration. Reusing a framework can reduce bespoke engineering, but MAGNE-specific changes require their own testing and review.

What reuse does and does not establish

  • Execution and rollup components have separate responsibilities; deployment requires more than an execution client.
  • Using OP Stack does not automatically establish Superchain membership, a live bridge or interoperability with every other rollup.
  • Data publication, settlement contracts, proof configuration and upgrade authority must be documented for the actual network.
